시행일 / Effective date: 2026-10-30

## 한국어

LAZIST는 개인용 일정관리 데스크톱 앱입니다.

**할 일 데이터**
- 작업·리스트·태그·설정 등은 로그인한 본인 계정의 데이터베이스(Supabase)에 저장되며, 본인만 읽고 쓸 수 있습니다.
- 이 데이터를 다른 사람과 공유하거나 판매하지 않습니다.

**구글 로그인**
- 로그인에는 구글 계정의 이메일과 이름(프로필)만 사용합니다.

**구글 캘린더 (선택)**
- 사용자가 직접 "구글 캘린더 연결"을 누른 경우에만, 캘린더 **읽기** 권한(`calendar.readonly`)을 요청합니다.
- 받아 온 일정은 그 기기의 LAZIST 달력 화면에 함께 보여 주는 데에만 씁니다. 일정을 고치거나 만들지 않습니다.
- 구글 연결 정보와 받아 온 일정은 **그 기기에만** 저장(운영체제 암호화)하며, LAZIST 서버나 제3자에게 보내지 않습니다.
- 앱의 "연결 끊기" 또는 구글 계정의 [타사 연결 관리](https://myaccount.google.com/connections)에서 언제든 권한을 거둘 수 있습니다.
- LAZIST의 구글 API 데이터 사용은 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)(제한적 사용 요건 포함)을 따릅니다.

## English

LAZIST is a personal task-management desktop app.

**Task data**
- Tasks, lists, tags and settings are stored in the signed-in user's own database (Supabase) and are accessible only to that user.
- This data is never shared with or sold to anyone.

**Google Sign-In**
- Only the Google account's email and name (profile) are used to sign in.

**Google Calendar (optional)**
- Only when the user clicks "Connect Google Calendar", LAZIST requests **read-only** calendar access (`calendar.readonly`).
- Events are used solely to display them alongside tasks in the app's calendar view on that device. LAZIST never edits or creates events.
- The Google connection and fetched events are stored **only on that device** (encrypted by the operating system) and are never sent to LAZIST servers or any third party.
- Access can be revoked at any time via "Disconnect" in the app or in your Google Account's [third-party connections](https://myaccount.google.com/connections).
- LAZIST's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
